Val av publiceringsplattform

Jag har valt att använda mig av Render för att publicera min webbplats.

Kravet för val av plattform är att denna inte ska vara baserad på FTP/SFTP. Plattformen får även gärna vara en plattform vi inte använt tidigare.

Mitt val att använda Render, trots att jag använt Render tidigare, baseras på att jag önskar ha mina webbplatser samlade på en plattform. Jag inser dock att det kan vara bra att testa flera plattformar, så jag ska ta till mig av detta framöver i framtida publiceringar.

Render har inbyggt stöd för följande språk:

  • JavaScript och TypeScript (via Node.js eller Bun)
  • Python
  • Ruby
  • Go
  • Rust
  • Elixir

Render har även stöd för publicering av statiska webbplatser skapade med HTML, CSS och Javascript.


Kostanden för att använda Render varierar. Enkla statiska webbplatser kan publiceras gratis. Kostnaden för andra tjänster varierar beroende på vilken typ av webbplats som publiceras samt vilken plan användaren har valt.

Följande planer finns:

  • Hobby - $0/månad
  • Pro - $25/månad
  • Scale - $499/månad
  • Enterprise - Skräddarsydd prissättning

Utöver kostnaden för själva planen kan det tillkomma avgifter för använding av olika resurser.


Fördelarna med Render enligt mig är att publiceringen är väldigt smidig. Speciellt när man arbetar med Vite och GitHub som jag gör i denna uppgift. Jag tycker även att det är smidigt att ha alla webbplatser samlade på en plattform. Jag personligen har aldrig haft något strul med mina publiceringar på Render.

Nackdelarna med att använda Render igen är att jag inte utvecklar någon erfarenhet av att använda andra publiceringsplattformar. Detta är något som jag ska ta till mig av och fundera på att använda andra plattformar framöver.


När jag ska publicera min webbplats på Render går jag tillväga på följande sätt:

  • Med kommandot npm run build bygger Vite webbplatsen och optimerar filerna för publicering.
  • En dist-katalog skapas och innehåller de färdiga filerna för webbplatsen.
  • Jag kopplar sedan mitt repository i GitHub till Render och anger npm run build som Build Command och dist som Publish Directory.
  • Render sköter då publiceringen med informationen jag angett.

Väldigt smidigt enligt mig!
