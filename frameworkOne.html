Bootstrap

Bootstrap är ett front-end-ramverk som effektiviserar utvecklingen av webbplatser och applikationer. Genom att erbjuda utvecklaren färdiga komponenter och verktyg, till exempel knappar, formulär och navigeringsmenyer, behöver dessa inte skapas från grunden. Bootstrap innehåller även ett inbyggt system för responsiv design, vilket gör det enklare att anpassa webbplatsens utseende efter olika skärmstorlekar.

Bootstrap

Fördelarna jag kan se med att använda Bootstrap är att utvecklingen blir mycket mer effektiv när man väl har lärt sig hur Bootstrap fungerar. Genom att kunna använda de inbyggda verktygen slipper man själv sitta och skapa designen för varje element manuellt på samma sätt. Det är även en stor fördel att slippa arbeta med responsiviteten för webbplatsen då detta är ett väldigt tiskrävande moment i utvecklingen. Även designen av tabeller och formulär underlättades mycket av att använda Bootstrap, speciellt när det kommer till responsiviteten av tabeller som annars kan vara lite klurigt att få till.

Den enda nackdelen jag sett när jag använt Bootstrap är att det var lite otydligt, enligt mig, vart på hemsidan jag hittade det som gällde för version 6.0 respektive 5.3.8 som jag använder. När jag hittade rätt version löste det sig bättre. I början kändes det även lite omständigt att använda Bootstrap, men efter lite användande kom man in i det och då kändes det faktiskt väldigt användbart.

Sammantaget har jag gillat att använda Bootstrap och kan tänka mig att göra det igen.
