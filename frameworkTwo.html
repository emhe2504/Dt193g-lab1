Tailwind

Tailwind är ett CSS-ramverk som används för att bygga webbplatser på ett effektivare sätt genom att lägga CSS-klasser direkt på elementen i HTML-koden. Tailwind innehåller många olika hjälpklasser som kan användas för att styra webbplatsens utseende och layout. Exempel på detta är färger, marginaler, responsivitet, flexbox och textstorlek.

Tailwind

Fördelarna jag kan se med att använda Tailwind är absolut likvärdiga med de för Bootstrap. Utvecklingen blir mycket mer effektiv när man slipper skriva långa css-filer och kan använda färdiga och namnsatta klasser. När man redan satt sig in i Bootstrap och lärt sig hur det fungerar blir det även tydligt hur Tailwind fungerar, då man kan se likheter. Sedan återkommer vi till den stora fördelen, nämligen att slippa arbeta med responsiviteten för webbplatsen då detta är ett väldigt tidskrävande moment i utvecklingen.

Jag har inte upplevt några särskilda nackdelar med Tailwind. Det tar såklart lite tid att hitta alla klasser, men det tar även mycket tid att skriva en hel css-fil. Något som skulle kunna ses som en nackdel är att HTML-koden kan upplevas lite rörig.

Sammantaget så har jag tyckt om att använda CSS-ramverk, både Bootstrap och Taildwind. Tror faktiskt att jag gillar Tailwind lite mer. Jag tror även att om man fortsätter använda liknande ramverk framöver så kommer det nog gå ännu bättre samt att utvecklingen blir ännu mer effektiv med tiden.
